NautiLink — Documentation de référence

Ce dépôt contient la synthèse des décisions exprimées pendant les échanges de définition de NautiLink Web et Android.

Organisation des documents

- "docs/cahier-des-charges.md" : périmètre fonctionnel et décisions connues.
- "docs/todo-et-points-a-confirmer.md" : éléments à étudier et questions encore ouvertes.
- "docs/regles-metier.md" : règles détaillées de navigation, GPS, SOS, partage et synchronisation.

Statut des informations

- Décidé : explicitement confirmé par le porteur du projet.
- À confirmer : sujet évoqué mais dont le comportement exact n'a pas encore été choisi.
- À étudier : élément inscrit dans la to-do, sans engagement d'intégration.

Cette documentation est une base de reprise. Elle ne remplace pas les validations techniques, UX, sécurité, légales ou les spécifications d'API.
