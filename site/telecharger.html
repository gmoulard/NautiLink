Installer NautiLink

NautiLink n'est pas encore publiée sur Google Play ni sur l'App Store. Vous l'installez directement depuis ce site.

Deux applications sont proposées :

  • NautiLink, la version de production, en bêta : votre compte sur le serveur de NautiLink, vos bateaux, vos navigations ; la dernière construction publiée ici est la production ;
  • NautiLink démo, la démonstration V0 : des données d'exemple pour découvrir tous les écrans, sans compte ; rien n'est réellement envoyé. Elle est terminée et ne change plus.

NautiLink est en version bêta et n'est pas un équipement de sécurité. N'en dépendez pas en mer : en cas de détresse, canal 16 de la VHF ou 196.

Production (bêta)

NautiLink

La dernière construction publiée ici est la version de production de NautiLink, en bêta, branchée sur le serveur de production.

Créez votre compte dans l'application ou sur la plateforme Web, puis connectez-vous sur le téléphone : il est associé à vos bateaux.

Ce que fait cette version :

  • compte, connexion, association du téléphone à vos bateaux ;
  • démarrage d'une navigation (destination en texte ou sur une carte, personnes à bord, personnes alertées, « Ajouter une personne »), positions automatiques écran éteint, position, NOTE, Photo, Vocal, fin de navigation ;
  • SMS par la carte SIM sur Android, envoyés automatiquement une fois l'envoi de SMS autorisé : SOS, positions, notes, photos (avec le lien, et le MMS prérempli si vous le voulez), notes vocales, début, fin et invitations ; sans autorisation, ils s'ouvrent préremplis dans l'application SMS ;
  • alerte SOS : e-mails envoyés par le serveur, SMS SOS sur Android ; sur iPhone, par Internet seulement ;
  • trace pour vous : chaque envoi vous parvient aussi par SMS (Android) et par e-mail, et le journal complet par e-mail à la fin de la navigation ;
  • contacts, invitations, paramètres, langue, historique des alertes SOS ;
  • navigations suivies : tableau de bord et page de la navigation avec la carte, le journal, les photos et les notes vocales.

Pas encore ouverts : connexion par Google et Apple, notifications push, achat de l'abonnement. Hors connexion, les envois sont gardés sur le téléphone et partent au retour du réseau.

Télécharger l'APK de démonstration V0

Version V@VERSION_APK@, build @BUILD_APK@, construite à partir du commit @COMMIT_APK_COURT@.

  1. Ouvrez cette page sur votre téléphone Android et touchez le bouton de téléchargement (production ou démonstration V0).
  2. Ouvrez le fichier téléchargé. Android demande d'autoriser votre navigateur à installer des applications : touchez « Paramètres », activez « Autoriser cette source », puis revenez.

iPhone

Démonstration V0 : deux façons, sans l'App Store

1. Sur l'écran d'accueil (le plus simple)

La démonstration Web s'ouvre comme une application, sans compte ni installation.

  1. Ouvrez la démonstration Web dans Safari sur votre iPhone.
  2. Touchez le bouton de partage, puis « Sur l'écran d'accueil ».
  3. Touchez « Ajouter » : l'icône NautiLink apparaît avec vos applications.

2. Application iPhone non signée (pour les curieux)

Apple n'autorise l'installation hors App Store qu'avec une signature. Le fichier proposé ici n'est pas signé : vous le signez vous-même avec votre identifiant Apple, grâce à un outil d'installation sur ordinateur comme AltStore ou Sideloadly.

Télécharger l'IPA de démonstration V0 non signé

Version V@VERSION_IPA@, build @BUILD_IPA@, construite à partir du commit @COMMIT_IPA_COURT@.

  1. Sur votre ordinateur, installez AltStore ou Sideloadly en suivant leurs instructions.
  2. Branchez l'iPhone, ouvrez l'outil, choisissez le fichier IPA téléchargé et connectez-vous avec votre identifiant Apple.
  3. Sur l'iPhone, activez le mode développeur si iOS le demande : Réglages, Confidentialité et sécurité, Mode développeur, puis redémarrez.
  4. Faites confiance au profil : Réglages, Général, VPN et gestion de l'appareil, votre identifiant Apple, « Faire confiance ».

Avec un identifiant Apple gratuit, l'application cesse de s'ouvrir au bout de 7 jours : il faut la réinstaller ou la renouveler avec l'outil. Le nombre d'applications installées ainsi est aussi limité. Ces règles sont celles d'Apple et peuvent changer.

Empreintes des fichiers

Le fichier SHA256SUMS.txt donne l'empreinte SHA-256 de chaque fichier. Elle permet de vérifier que le fichier téléchargé est bien celui construit par le projet, par exemple avec sha256sum nautilink.apk.
