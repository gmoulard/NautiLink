{{if .Actif}}Changer le code{{else}}Poser le code{{end}}

Collez, tel que le portail de Météo-France le donne, sans rien ajouter devant : la clé d'API (« API Key », qui commence par « eyJ »), ou la chaîne de l'identifiant d'application (pour « Authorization: Basic »), ou « identifiant:secret ». Le serveur ajoute lui-même l'en-tête. Un jeton d'une heure n'est pas accepté : il cesserait de marcher aussitôt. Le code est vérifié auprès de Météo-France avant d'être enregistré ; un code refusé n'est pas enregistré.
